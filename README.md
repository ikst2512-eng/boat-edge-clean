## 画面の順番（変更には理由とテストが必要）
1. **次に締切の3レース**：公式の当日開催データから、現在時刻より後の締切だけを時刻順に最大3件表示。締切済みは含めない。該当なしは空状態として明示。
2. **レース検索**：日付・全国24場（折りたたみ）・1〜12R。ユーザーの手動選択を勝手に上書きしない。
3. **選択レースの詳細タブ**：［出走表・成績］［展示］［3連単予想］［結果・答え合わせ］の4つ。常に選択中の1つだけを表示。予想を初期タブとし、URLの `screen` で再現可能。
4. **再読み込み**：表示しているデータだけ更新。不要な裏側通信や重複ジョブを増やさない。

## 各タブに当てはめる情報
- **出走表**：艇番、選手、全国・当地成績、モーター、ボート。取得できない値は「—」。
- **展示**：公式展示タイム・チルト、スタート展示の進入/ST、オリ展の1周/回り足/直線を**1〜6艇の同じ比較表**へ統合。提供なし/未公開/通信失敗を区別。
- **予想**：初回Git原本と締切前保存を証明できる予想だけ、純粋なモデル確率順でTop3/Top5/Top10。オッズで勝手に並べ替えない。予想がなければその理由を明記。
- **結果**：確認済み確定結果を表示し、検証済みの事前予想だけでTop3/5/10の的中照合。事前予想が欠ける場合は判定保留。結果を予想生成へ戻さない。
