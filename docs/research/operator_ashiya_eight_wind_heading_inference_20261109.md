## 8通りの仮進行方位を検証
方位は0°=北、45°刻み。**生方位は風が「来る方向」**と仮定し、スタートから1マークへの艇の進行軸との符号付き角差で
`head / oblique_head / cross_left / cross_right / oblique_tail / tail`
の6幾何ラベルを作る。次に主催者の文字表示に合わせ、head+oblique_head→向い風、oblique_tail+tail→追い風、左右横風は区別したまま比較する。

| 進行方位の候補 | 公式文字表示と整合する方位数／8 |
|---|---:|
| 北0° | 2/8 |
| 北東45° | 4/8 |
| **東90°** | **8/8** |
| 南東135° | 4/8 |
| 南180° | 2/8 |
| 南西225° | 0/8 |
| 西270° | 0/8 |
| 北西315° | 0/8 |

したがって**上の幾何・ラベル変換という研究上の仮定の下では東90°が唯一整合**する。二次資料Aの芦屋「東向き」候補と一致し、別実装のスタンド方位を向かい・追いの方位へ読み替える方式の危険性を補足する。ただし、運営者の言葉がそもそも地理方位を内部変換した結果の可能性がある。この比較は**独立した水面図の真方位計測にも、風矢印のFROM/TO確認にも代わらない**。
