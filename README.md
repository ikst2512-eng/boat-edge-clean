# BOAT EDGE CLEAN — 固定画面テンプレート

このサイトは **1ページ・レース中心・スマホ優先** で統一する。画面を先に固定し、既存の検証済みデータを各枠へ当てはめる。ボーターズの操作の分かりやすさを参考にするが、独自デザインと証拠基準を維持する。

## 画面の順番（変更には理由とテストが必要）
1. **次に締切の3レース**：公式の当日開催データから、現在時刻より後の締切だけを時刻順に最大3件表示。締切済みは含めない。該当なしは空状態として明示。
2. **レース検索**：日付・全国24場（折りたたみ）・1〜12R。ユーザーの手動選択を勝手に上書きしない。
3. **選択レースの詳細タブ**：［出走表・成績］［展示］［3連単予想］［結果・答え合わせ］の4つ。常に選択中の1つだけを表示。予想を初期タブとし、URLの `view` で再現可能。
4. **再読み込み**：表示しているデータだけ更新。不要な裏側通信や重複ジョブを増やさない。

## 各タブに当てはめる情報
- **出走表**：艇番、選手、全国・当地成績、モーター、ボート。取得できない値は「—」。
- **展示**：公式事前データの展示タイム・ST・チルト。未公開と通信失敗を区別。
- **予想**：初回Git原本と締切前保存を証明できる予想だけ、純粋なモデル確率順でTop3/Top5/Top10。オッズで勝手に並べ替えない。予想がなければその理由を明記。
- **結果**：確認済み確定結果を表示し、検証済みの事前予想だけでTop3/5/10の的中照合。事前予想が欠ける場合は判定保留。結果を予想生成へ戻さない。

## 完成条件
- スマホ実ブラウザで締切前表示が **0〜3件**、4タブが正常切り替え、予想が存在するレースで買い目が表示される。
- 保存済みの確定結果と事前予想で答え合わせができ、予想欠落では後付け採点しない。
- GitHub Pagesの公開版が最新の `index.html` を配信することを確認する。
- GitHubコミットやJavaScript構文検証だけでは完成としない。

原則として **既存の `index.html` を改善し、新しいページ・重複機能・重複ワークフローを追加しない**。
