# Independent research capture staging branch

This isolated branch is NOT the production parent model. A stand-alone workflow performs only restricted HTML capture in the UTC+9 pre-race 20–12-minute window; it does NOT produce boat-race probabilities or scoring.

Deployment of this workflow to a non-default branch is **not an executed workflow run**. GitHub `workflow_dispatch` generally requires the workflow to exist on the default branch before it can be triggered. Before any experiment, review security, sources, cutoff, race identity, and privacy. Results-containing pages must not be used as prediction input. Timestamps are runner-local, not independently certified.
