# 全国24場・風速別 実進入1コース1着率の3か月研究（2026-11-06）

**研究専用 / 本番補正禁止 / 事後結果CSVでの観測集計。**

## 取得完了の範囲と不確実性

- 対象は2026年8月1日〜10月31日、**92日、24場、14,109行**。6艇の実進入等が揃わない**139行**を除外し、**13,970レース**を集計。
- BoatraceCSVのGitHub上の準リアルタイム結果CSVを使い、各日別ファイルのGit blob SHAを保存。一次資料であるBOAT RACE公式の競走成績ダウンロード原本との**独立照合は未完了**。プレビューや本番のT−12原本でもない。
- 列定義の罠：`1着_艇番` (1号艇か) と `1コース_艇番` (実1コースの艇か) は違う。決まり手 `逃　げ`, `差　し`, `抜　き` の全角空白を正規化。風向の1〜8コードは今のところ**未変換**。他の二次資料の「向かい／追い」を割り当てない。
- 同じ2026/08/01〜10/31のBOAT RACE公式各場「コース別1着率」に照らし、研究CSV再集計の24場の差は **最大1.78pt**。ただし分母・除外条件が違うので一致ではなく整合性の**傍証**にとどめる。
- 元データとスキーマ: https://github.com/BoatraceCSV/boatracecsv.github.io / https://boatracecsv.github.io/docs/data/results.html
- 公式場データ: https://www.boatrace.jp/owpc/pc/extra/data （各場の`data/stadium?jcd=xx`）。

### 同じ場でも月ごとに方向が違う

- **三国**：1C差 8月 −15.47pt（微風112 / 5m以上24件）、9月 −9.57pt（98 / 54件）、10月 **＋6.39pt**（89 / 61件）。
- **大村**：8月 −7.58pt（101 / 32件）、9月 ＋10.45pt（139 / 50件）、10月 ＋18.15pt（137 / 22件）。**符号の安定性がない**。
- **江戸川**：8月 −5.67pt（51 / 55件）、9月 −5.65pt（67 / 38件）、10月 −6.79pt（63 / 61件）。月別方向は一致するが、この事実のみから風が原因とは断定できない。
- **唐津**：8月 −27.92pt（57 / 59件）、9月は微風側9件につき比較不可、10月 −18.86pt（105 / 50件）。強い差がありつつ、月ごとの標本が偏る。

## 次に必要な厳格な実験

1. 公式競走成績の一次原票との少なくともサンプル突合 → 分母と除外の非ランダム性の監査。
2. 風向コードと24場のホーム方位（向かい・追い・斜め・横）の検証。方位表は二次情報として保持し、独立検証前は係数にしない。
3. 場×月×風向×風速、波高、実進入の助走距離、2C壁、展示ST/タイム、一周/回り足/直線、潮位、級別、時間帯で層別。分母不足・多重比較と不確実性を明示。
4. **事後の結果CSVの気象は本番予想に流入禁止**。締切T−12前の公式受信原本・6艇完全性・Git初回時刻が成立する実レースのみ、凍結した候補モデルの評価母集団とする。
5. 新規期間で現行モデル vs 候補を同じレース集合・同じ確率基準によりTop1/3/5/10、Brier、LogLossで比較。改善が実証されるまで本番ロジック不変。
